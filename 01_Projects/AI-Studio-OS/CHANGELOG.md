# 更新记录（CHANGELOG）

所有版本变化都记录在这里，新版本在前。

## v0.1.5 —— 2026-09-17

**新增：批量重命名（月度计划 W2 的原始目标达成）**

- 新函数 `core.build_rename_plan()`：两种改名方式——
  - **加序号**：前缀 + 三位序号（如 `照片-001.jpg`），扩展名自动保留
  - **查找替换**：文件名中的指定文字替换（如 IMG → 武当山）
- 新按钮「⑥ 批量重命名」：选文件（可多选）→ 选方式 → 预览 → 确认执行
- 安全规则与整理一致：名字没变→跳过；新名被占用→冲突不覆盖；文件消失→跳过
- 改名走同一套日志/撤销体系：主窗口「④ 撤销上次」可直接恢复改名
- 报告新增 `[改名] 旧名 → 新名` 条目；移动条目改为 `[移动]`
- 测试新增 11 组（规划/执行/撤销/查找替换/4 个边界场景），累计 76 项全部通过

## v0.1.3 —— 2026-09-17

## v0.1.0 —— 2026-09-17

智能文件工作台第一个正式版本。

### 新增

- **core.py**：核心逻辑（扫描 / 规划 / 执行 / 日志 / 撤销），全部函数独立于界面
- **app.py**：图形界面，四个按钮按序操作（选择→扫描预览→执行→撤销）
- **test_core.py**：28 项自动化测试，覆盖安全拦截、预览零修改、执行、日志、撤销全链路

### 安全特性

- 拒绝整理系统目录（C:\Windows、Program Files 等）
- 拒绝整理盘符根目录和个人重要目录（桌面、文档、下载、图片）
- 只移动、永不删除；同名冲突一律跳过不覆盖
- 执行前强制预览 + 弹窗确认
- 每次操作写撤销日志，支持一键恢复

### 测试结论

28 项核心逻辑测试 + GUI 冒烟测试全部通过（详见 TESTING.md）。
