# 更新记录（CHANGELOG）

所有版本变化都记录在这里，新版本在前。

## v0.1.0 —— 2026-09-17

智能文件工作台第一个正式版本。

### 新增

- **core.py**：核心逻辑（扫描 / 规划 / 执行 / 日志 / 撤销），全部函数独立于界面
- **app.py**：图形界面，四个按钮按序操作（选择→扫描预览→执行→撤销）
- **test_core.py**：28 项自动化测试，覆盖安全拦截、预览零修改、执行、日志、撤销全链路

### 安全特性

- 拒绝整理系统目录（C:\Windows、Program Files 等）
- 拒绝整理盘符根目录和个人重要目录（桌面、文档、下载、图片）
- 只移动、永不删除；同名冲突一律跳过不覆盖
- 执行前强制预览 + 弹窗确认
- 每次操作写撤销日志，支持一键恢复

### 测试结论

28 项核心逻辑测试 + GUI 冒烟测试全部通过（详见 TESTING.md）。
