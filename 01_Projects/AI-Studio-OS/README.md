# AI 个人工作室操作系统（AI Personal Studio OS）

> 一套面向个人开发者、学生和小型工作室的轻量级工具系统。
> 目标：帮助用户完成文件整理、数据处理、任务自动化、电子信息测控和作品展示。

## 重要说明

"操作系统"是**项目名称**。第一阶段实际开发的，是运行在普通 Windows 电脑上的**应用软件**，不是开发 Windows/Linux 系统本身。

| 2 | 数据处理助手——CSV 导入清洗、统计、图表、报告 | 未开始 |

## 产品一：智能文件工作台 v0.1.6

**位置**：`workbench/` 文件夹
**打开方式**：双击 `workbench/app.py`，或用打包好的 `C:\DevHub\05_Output\智能文件工作台 v0.1.6.exe`
**测试方式**：命令行运行 `python test_core.py`（76 项自动化测试，当前全部通过）

功能一览：选择文件夹 → 扫描预览（绿色=将移动，橙色=同名冲突，灰色=跳过）→ 确认执行 → 一键撤销 → 自动生成整理报告；支持按类型/按日期整理、自定义规则、递归整理、批量重命名、拖拽文件夹直接整理。

详细用法见 `docs/智能文件工作台-使用说明.md`。

## 产品二：数据处理助手 v0.1.1

**位置**：`datatool/` 文件夹
**打开方式**：双击 `datatool/app.py`，或用打包好的 `C:\DevHub\05_Output\数据处理助手 v0.1.1.exe`
**测试方式**：命令行运行 `python test_core.py`（36 项自动化测试，当前全部通过）

功能一览：选择 CSV 文件 → 勾选清洗选项（去空格/删空行/去重/智能数字列等）→ 预览清洗结果 → 统计信息 → 导出为新文件（原文件永不修改）。

详细用法见 `docs/数据处理助手-使用说明.md`。

## 研发约定

- 每个功能必须先测试、后发布，不编造测试结果
- 涉及用户文件的操作必须有预览和撤销机制
- 永不删除用户文件，只做可逆操作
- 技术选型优先免费、本地、简单、稳定
