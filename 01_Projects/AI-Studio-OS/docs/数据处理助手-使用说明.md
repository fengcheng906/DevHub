# 数据处理助手 使用说明（v0.2.0）

> 帮你把 CSV 表格数据洗干净、筛出想要的行、排好顺序、画成图，再存成新文件。
> **你的原始文件永远不会被修改**，结果保存在新文件里。

## 一、怎么打开

两种方式，选一个：

1. 直接双击桌面或 `C:\DevHub\05_Output\` 里的 **数据处理助手 v0.2.0.exe**
2. 或者双击 `C:\DevHub\01_Projects\AI-Studio-OS\datatool\app.py`

## 二、使用步骤（按顺序）

**第 1 步：准备数据**
把你的表格用 Excel / WPS 打开，「另存为」→ 格式选 **CSV（逗号分隔）**。
（目前只认 .csv 文件，Excel 的 .xlsx 直接打开还不支持。）

**第 2 步：选择文件**
点「① 选择 CSV 文件」，选中你刚保存的 csv 文件。
选中后表格里会显示原始数据，下方状态栏显示行数、列数和识别到的编码。

**第 3 步：勾选清洗选项**（一般用默认的就行）

| 选项 | 作用 | 建议 |
|---|---|---|
| 去首尾空格 | 去掉单元格内容里多余的空格 | 勾上 |
| 删整行空白 | 删掉整行都是空的行 | 勾上 |
| 删整列空白 | 删掉整列都是空的列 | 按需 |
| 删重复行 | 几列内容完全一样的行只留一条 | 勾上 |
| 删含空白格的行 | 只要这一行有空白格就整行删掉 | 按需 |
| 智能数字列 | 整列都是数字的列自动整理成规范数字 | 勾上 |
| 空白格填成 | 把空白格填成你写的值（比如 0），留空表示不填 | 按需 |

**第 4 步：预览**
点「② 预览清洗结果」，表格会显示清洗后的样子，状态栏告诉你"清洗：N 行 → M 行"。
不满意就改选项再预览，点「恢复原始预览」可以随时看回原样。

**第 5 步：筛选（挑出想要的行，可选）**

在「筛选与排序」卡片里：

1. 第一个下拉框选**列**（比如"成绩"）
2. 第二个下拉框选**条件**（等于 / 包含 / 大于 / 小于 / 为空……一共 10 种）
3. 填上要比较的内容（选"为空/不为空"就不用填）
4. 点「⑤ 筛选」，表格立刻只显示符合条件的行

例子：想看及格的人 → 列选"成绩"，条件选"大于等于"，值填"60"。
想撤掉筛选，点「清除筛选/排序」就回到之前的样子。

**第 6 步：排序（把行排整齐，可选）**

在「筛选与排序」卡片里：选列 → 点「升序 ↑」或「降序 ↓」。
- 数字列（成绩、金额）按大小排，空白永远排在最后
- 文字列按顺序排，"第2组"会正确地排在"第10组"前面

**第 7 步：画柱状图（可选）**

在「筛选」那行选好一列，点下方「⑤ 画柱状图」：

- 选"班级"这类文字列 → 画出每个班各有多少人
- 选"成绩"这类数字列 → 自动分段，画出分数段分布图（比如 60~69 分有几个人）

**第 8 步：统计 / 导出**
- 「③ 统计信息」：弹窗显示每一列有多少个值、缺多少、不重复多少个，数字列还有最小/最大/平均值。
- 「④ 导出结果」：把清洗后的数据存成新文件，默认叫「原文件名（清洗后）.csv」，和原文件放在同一个文件夹。**原文件不动。**

## 三、常见问题

**Q：打开后表格是乱码？**
A：一般不会。软件会自动识别 utf-8 和 gbk 等常见编码。如果真遇到乱码，用记事本打开原文件 → 另存为 → 编码选 UTF-8，再导入试试。

**Q：导出的文件用 Excel 打开乱码？**
A：不会。导出的文件是专门处理过的（带 BOM 的 UTF-8），Excel 双击直接打开中文正常。

**Q：我的一份数据里有"约100"这种文字混在数字里？**
A："智能数字列"很谨慎：一列里只要有一个不是纯数字，整列保持原样不硬转，绝不会把你的数据改坏。

**Q：能直接读 Excel（.xlsx）吗？**
A：v0.1.0 还不行，请先在 Excel 里另存为 CSV。直接读 xlsx 已列入下版本候选功能。
