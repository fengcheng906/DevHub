# 智能文件工作台 v0.1 —— 使用说明

> 写给第一次用的人。照着做就行，每一步都说清了会看到什么。

## 这是什么软件？

帮你把**乱糟糟的文件夹**一键整理干净的小工具。它会：

1. 把图片归到 `图片/` 文件夹
2. 把文档归到 `文档/` 文件夹
3. 视频、音乐、压缩包、安装程序同理
4. 每一步都可以先预览再执行，做完还能一键撤销——**放心，不会弄丢文件**

## 怎么打开？

**方法（推荐）**：打开文件夹 `C:\DevHub\01_Projects\AI-Studio-OS\workbench`，**双击 `app.py`**。

会弹出一个标题为「智能文件工作台 v0.1」的窗口。

> 如果双击没反应，换这个方法：先双击桌面的「Git Bash」图标，在黑窗口里输入：
> ```
> python "C:/DevHub/01_Projects/AI-Studio-OS/workbench/app.py"
> ```

## 四个按钮，按顺序用

### 最快速上手（v0.1.6 起）

**直接把文件夹拖进软件窗口**就能选中它——不用点「① 选择文件夹」。拖进来后照常点「② 扫描预览」→「③ 执行整理」。

> 也可以把单个文件拖进来，软件会自动用它所在的文件夹。

### ① 选择文件夹

点它 → 弹出浏览窗口 → 找到并选中你想整理的文件夹 → 点「选择文件夹」。

**注意**：软件会拒绝整理系统目录（Windows、Program Files）和你的桌面、文档、下载等重要位置——这是故意的安全保护。想练习的话，新建一个专门的文件夹来玩。

### ② 扫描预览

点它，中间会出现一张表格，每个文件一行：

| 颜色 | 状态 | 意思 |
|---|---|---|
| 绿色 | ✔ 将移动 | 点执行后会被移进分类文件夹 |
| 橙色 | ⚠ 同名冲突 | 分类文件夹里已有同名文件，**不会动它**，留你处理 |
| 灰色 | — 跳过 | 没有匹配规则（比如 .xyz 文件）或隐藏文件 |

**整理方式**（底部两个圆点选项）：

- **按类型**：文件归到 图片/文档/视频/音乐/压缩包/安装程序 文件夹（v0.1.2 新增替代：按日期）
- **按日期**：文件按最后修改的月份归到 `2026-09/` 这样的文件夹，不按类型区分，所有文件都归档

**包含子文件夹**（勾选框，v0.1.4 新增）：

- 不勾：只整理所选文件夹第一层的文件（推荐第一次用保持不勾）
- 勾选：子文件夹（包括一层套一层的）里的文件也会被整理到顶层分类目录
- 撤销时会精确放回原来的子文件夹位置；你自己建的空子文件夹会保留

**这一步只是"看"，没有动任何文件。**

### ③ 执行整理

确认表格没问题后点它 → 弹出确认框 → 点「是」→ 完成。

软件会显示移动了几个文件，并自动在文件夹里建一个 `_工作台记录` 文件夹，里面存着：
- `report_xxx.txt`：人看的整理报告
- `undo_xxx.json`：撤销用的记录

### ④ 撤销上次

后悔了？点它 → 确认 → 所有被移动的文件**全部回到原位**。

## 第一次用，建议这样练习（5 分钟）

1. 在 `C:\DevHub\02_Learning` 里新建文件夹 `试一试`
2. 从别处复制几个不同类型的文件进去（图片、PDF、MP3 随便什么）
3. 打开工作台 → 选中 `试一试` → 扫描预览 → 执行
4. 打开资源管理器看看：文件都分类好了
5. 回到软件点「撤销上次」→ 再看：文件全回来了

玩熟了再整理真实文件夹。**养成习惯：整理前看一眼预览，心里有数再执行。**

## 常见问题

**Q：双击 app.py 没反应？**
用上面说的 Git Bash 方式运行，并把报错发给 AI 助手。

**Q：误把重要文件夹整理了？**
立刻点「④ 撤销上次」就能恢复。

### ⑤ 规则管理（v0.1.3 新增）

点左下角「⑤ 规则管理」，可以**不改代码**直接增删分类规则：

- 每行一条，格式：`类别名称: .扩展名1 .扩展名2`（冒号用英文中文都可以）
- 例：想修图软件的文件归一类，就加一行 `设计稿: .psd .ai .fig`
- 点「保存」后，下次「扫描预览」就按新规则来
- 点「恢复默认规则」可以一键还原
- 写错格式（比如扩展名忘了加点）会明确告诉你**第几行**有问题

### ⑥ 批量重命名（v0.1.5 新增）

点左下角「⑥ 批量重命名」，给一堆文件统一改名：

1. 在上方列表里**选中要改的文件**（按住 Ctrl 点可以选多个）
2. 选改名方式：
   - **加序号**：填一个前缀，文件变成 `前缀001.jpg`、`前缀002.jpg`……扩展名自动保留
   - **查找替换**：填"查找"和"替换为"，文件名里的文字被替换（如 IMG → 武当山）
3. 点「预览改名」，下方列表显示每个文件改成什么（✕ 表示冲突不会改）
4. 满意了点「确认改名」→ 弹窗确认 → 执行
5. 改错了？回主窗口点「④ 撤销上次」就能全部改回来

**安全规则**：新名字和已有的文件重名时不会覆盖（显示 ✕）；名字没变的自动跳过。

**适合什么场景**：相机导出的 IMG_0001~IMG_0099、下载的视频乱名、作业照片统一命名。
