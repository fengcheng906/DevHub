【01_Projects】项目文件夹
  放所有正在开发的程序项目代码。
  每个项目一个子文件夹，比如 01_Projects\file-helper\

【02_Learning】学习材料
  放课程练习、跟我做的小练习代码。

【03_Notes】笔记
  放每周学习记录、电路笔记、商业思考笔记。
  文件名格式：2026-09-W1-周记录.md

【04_Assets】素材资料
  放图片、参考资料、下载的模板等。

【05_Output】输出成品
  放最终交付的东西：报告、导出的作品、截图等。
