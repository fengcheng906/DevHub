## 今天学过的（第 1 组）

| 命令 | 作用 | 例子 |
|---|---|---|
| `pwd` | 显示我现在在哪个文件夹 | `pwd` → `/c/Users/风城` |
| `ls` | 列出当前位置有什么 | `ls` → 显示文件和文件夹 |
| `cd 路径` | 移动到某个文件夹 | `cd /c/DevHub` |
| `mkdir 路径` | 创建文件夹 | `mkdir 02_Learning/day1` |

## 关键规则

1. **路径写法**：`C:\DevHub` 在命令行里写成 `/c/DevHub`（正斜杠、小写盘符）
2. **带斜杠的是文件夹**（`02_Learning/`），不带你的是文件（`README.txt`）
3. **cd 后面有空格**：`cd空格/c/DevHub`
4. **绝对路径 vs 相对路径**：
   - `/c/DevHub/02_Learning` = 从 C 盘根写起的完整地址（绝对路径）
   - `02_Learning/day1` = 从当前位置写起的地址（相对路径）
5. **文件夹命名行规**：用英文、不用空格（如 `day1`、`my-project`）
6. **提示符里的 `(main)`**：表示当前文件夹是 Git 仓库、在 main 分支上

## 即将学的（第 2 组，下次继续）

| 命令 | 作用 |
|---|---|
| `cd ..` | 退回上一层文件夹（两个点=上一级） |
| `echo 内容 > 文件名` | 把文字写进一个文件（文件不存在会自动创建） |
| `cat 文件名` | 查看文件里的内容 |
| `clear` | 清空屏幕（快捷键 Ctrl+L） |

## 实用技巧

- **↑ 方向键**：翻出之前输过的命令，不用重新打
- **Tab 键**：自动补全文件/文件夹名（输 `cd 02` 再按 Tab，自动补成 `02_Learning`）
- **Ctrl + C**：打错想重来，换新行
- **Ctrl + L**：清屏
