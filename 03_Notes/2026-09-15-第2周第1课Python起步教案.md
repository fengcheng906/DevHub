## 第 1 课目标（30—40 分钟）

1. 理解"程序 = 你写给电脑的指令清单"

3. 掌握 `print()` 和变量

## 教学流程

### 第 1 步：创建第一个程序（5 分钟）

在 VS Code 里：文件 → 打开文件夹 → 选 `C:\DevHub\02_Learning` → 新建文件 `hello.py` → 输入：

```python
print("你好，我是周承俊")
print("这是我的第一个程序")
```

运行方式（二选一）：
- VS Code 右上角"运行"按钮（三角图标）
- 终端里：`cd C:\DevHub\02_Learning` 然后 `python hello.py`

**应看到**：两行文字输出。
**常见错误**：`SyntaxError` = 检查括号引号是否成对；`can't open file` = 路径不对（Windows Python 要用 `C:\` 风格路径）。

### 第 2 步：变量（10 分钟）

```python
name = "周承俊"
age = 19
print("我叫", name, "今年", age, "岁")
```

讲解点：变量像"贴了标签的盒子"；`"19"` 和 `19` 的区别（文字 vs 数字）。

### 第 3 步：input 交互（10 分钟）

```python
your_name = input("你叫什么名字？")
print("你好呀，", your_name)
```

讲解点：input 拿到的东西永远是文字。
